# 测试策略与验收矩阵

## 验收分层

| 层 | 必验范围 |
| --- | --- |
| 领域单元 | Schema、坐标、机位、引用、关键帧、镜头区间、插值、删除关联、复制、预算和三方合并 |
| 应用单元 | 单次权威写入、固定历史、来源追加、CAS、同键异参与提交后丢回执 |
| 真实MCP | 全部声明动作、Skill资源、CLI互读、停用／卸载／重装、固定来源拒绝 |
| 真实渲染 | 所有程序素材、实际像素、两机位、帧间差异、PNG／GLB读取、MP4完整解码 |
| 真实Electron | 全幅布局、素材添加与直接编辑、变换控件、快捷键、机位、预演、恢复、导入导出、浅暗和窄窗 |
| 当前Codex | 同一已有连接发现Skill，实际新建工程与修改返工，独立渲染并回读 |
| 发行与目录 | 固定归档、双摘要、Tag、Release重新下载、公开中英页面与手机／桌面 |

## 负例与证据

测试同时覆盖相机位置等于目标、near≥far、重复／悬空ID、轨道目标丢失、镜头重叠、时长越界、负比例、非有限数、非法来源、坏JSON、预算、旧基线、丢回执、目录路径穿越及渲染超时。无窗口脚本不能在WebGL初始化失败时写成功报告。

快照、测试日志、实际输出与人工观看范围分别记录。程序预演的完整解码不能证明演员身份、最终材质或作者认可。Windows／Linux、干净系统、辅助技术与付费生成不由共用代码推导通过。

## v0.2.0增量验收

覆盖DS-15至20：二维坐标与朝向、拖动及缩放，逐镜起止采样与边界、单帧、旋转最短路径，台词来源与说话人引用，显式轴线、画外和几何遮挡、语速估时，镜头重排／时长／删除不丢元数据，旧工程读取与原键恢复。真实机器调用全部新增动作并跨CLI回读；真实Electron核对默认调度、双视图、镜头表、逐镜编辑、复制、浅暗窄窗和重开；实际渲染验证局部调度影响像素与GLB，完整解码MP4。本对话另用固定工程推进两版，不以测试夹具替代会话验收。

作品范围验收核对实际专业动作：视频作品可操作，其他作品拒绝专业写入；安装包须能通过正式宿主清单校验。专业对象类型与作品类型分别核验，导航筛选不能代替领域核验。
