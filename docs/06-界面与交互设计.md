# 界面与交互设计

工作面适用于视频作品，专业动作核验作品类型。v0.2.0运行包使用正式宿主Host API 1清单，不依赖未发布的作品导航筛选字段；插件安装状态在全局插件管理中查看。

## 信息结构

全幅独立工作面，左上一个返回入口。顶部两行紧凑工具栏；左侧素材，中央三维画布，右侧场景列表与属性，底部按需时间线。材质沿用宿主Radix与连续渐变，三维视口保持清晰中性背景。窄窗侧栏可折叠，主要画布不被三重导航包围。

## 交互合同

默认“俯视调度”，可切换“三维布景”。调度布局为左侧素材／对象属性、中央SVG平面、右侧真实透视预览与站位说明、底部镜头表；三维模式保留原有工作面。两种模式选择同一对象与当前帧，切换不重建工程。平面支持适配、缩放、平移、人物朝向与机位目标拖动，数值与键盘操作可替代手势。

镜头表呈现镜号、机位、时长、说话人、台词与估时；点击镜头同时定位帧与取景。当前镜头局部编辑开关在镜头外不可用，编辑位置明确显示作用范围；恢复基础调度为可撤销动作。站位说明与检查跟随当前帧和画幅，可复制当前／全部镜头。镜头表与高级关键帧分别展开，窄窗保留画布并允许侧栏折叠。

工具支持W移动、E旋转、R缩放、X吸附、F自由视角、1到9切机位、Del删除、Ctrl/Cmd+D复制、Ctrl/Cmd+Z撤销、Ctrl/Cmd+Shift+Z重做；文本输入、选择框及弹窗内不截获这些键。画布点选、对象直接拖放、Shift升降与OrbitControls手势共存，拖动物体时关闭轨道控制；转动视图不改机位，取景后显式更新机位。

场景列表支持名称、显隐、选择与删除；属性区提供精确位置、旋转、比例及相机光学参数。真实PNG、GLB和预演出口都有忙碌、取消、成功与错误反馈，导出不以空按钮或伪造进度替代。

空状态可让AI创建或手工建立。未保存稿在初次读取结束后才写入本机恢复buffer并保留最初基线；大场景优先保存当前稿及原请求，按900KiB裁剪撤销栈，未知原请求与同一当前稿共享内容；保存冲突显示本地／基线／远端，保留输入及原键。弹窗采用原生dialog、焦点回收与Escape取消。画布之外的核心信息可用键盘与数值操作。

## 逐项验收

布局、间距与对齐、排版、颜色、控件状态、交互分别评估，至少9/10；分数为有依据的设计判断，不冒充自动像素认证。真实Electron浅暗、正常与窄窗均保留证据，所有参考图功能逐项映射，未验证项不得补写通过。
