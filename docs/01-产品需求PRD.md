# 产品需求PRD

## 背景与产品目标

作者需要判断人物能否互相看见、道具是否挡住动作、镜头是否跨轴以及运动节奏是否成立。仅输出一段描述难以反复核对；让每轮AI重新生成三维网页又会消耗时间和Token。固定编辑器承载交互与渲染，外部Agent只提交结构变化，场景成为可积累的创作工程。

导演布景台是专业插件。它服务原创剧本、视频项目和分场预演，保持各作品身份独立。三维操作是可选入口，作者可直接提出目标，由Agent完成布景并交付可看的机位图与预演。

## 首版范围

| 范围 | 可观察结果 |
| --- | --- |
| 素材 | 站姿、行走、浅色人物；桌、椅、沙发、床、地毯、落地灯、植物；3m与5m墙、门洞墙、台阶；方块、球、圆柱、平板 |
| 编辑 | 选择、移动、旋转、缩放、吸附、直接拖放、升降、复制、删除、显隐、撤销与重做 |
| 镜头 | 自由、顶、前、侧视角；新增／改名／删除机位；摄影机位置、目标、焦距、近远平面与画幅 |
| 预演 | FPS、帧数、人物及摄影机关键帧、镜头切换、播放／暂停／定位 |
| 交付 | 当前及批量机位PNG、确定性PNG序列、可选MP4、场景JSON及包含动画与机位的GLB |
| 工程 | Core修订、来源、恢复、比较、备选、导入、完整导出、固定意见和Agent交接 |
| AI入口 | 专业动作与Schema、同包Skill、稳定CLI/MCP、无窗口渲染脚本 |

## 成功条件

Agent能从空作品建立场景、布置两个人及家具、设置多个机位和运动、渲染图与预演、按意见返工并回读旧新成果；停用或卸载后权威数据保留，重装可恢复。普通作者无需理解JSON或终端命令。
