# 产品需求PRD

## 背景与产品目标

作者需要判断人物能否互相看见、道具是否挡住动作、镜头是否跨轴以及运动节奏是否成立。仅输出一段描述难以反复核对；让每轮AI重新生成三维网页又会消耗时间和Token。固定编辑器承载交互与渲染，外部Agent只提交结构变化，场景成为可积累的创作工程。

导演布景台是专业插件。它服务原创剧本、视频项目和分场预演，保持各作品身份独立。三维操作是可选入口，作者可直接提出目标，由Agent完成布景并交付可看的机位图与预演。

## 首版范围

| 范围 | 可观察结果 |

| 预演 | FPS、帧数、人物及摄影机关键帧、镜头切换、播放／暂停／定位 |

## 成功条件

Agent能从空作品建立场景、布置两个人及家具、设置多个机位和运动、渲染图与预演、按意见返工并回读旧新成果；停用或卸载后权威数据保留，重装可恢复。普通作者无需理解JSON或终端命令。

## v0.2.0 俯视调度与分镜

同一场景提供俯视调度和三维布景两种工作模式，默认俯视调度：左侧对象及属性、中央米制平面图、右侧实时机位预览及站位说明、底部镜头表。平面图可拖动人物、家具、机位与朝向，呈现视锥、标注和对话轴线；与三维、保存、历史和渲染共用数据。

镜头表支持机位、秒数、说话人、台词参考与逐镜站位。基础布置、全局关键帧和镜头局部调度具有明确优先级；只改当前镜头时不改变其他镜头，镜头结束恢复全局状态。局部起止变换在镜头区间内插值。台词正式来源仍由宿主持有，插件只维护固定来源与调度参考。

站位说明、画外、朝向、遮挡、跨轴及台词时长均提供机器可读结果。空间检查以白模几何与指定帧为依据，语速是显式估算而非真实声音时长，不判断演员身份或表演。作者可复制当前／全部镜头说明，也可让Agent读取固定分镜报告后继续。
